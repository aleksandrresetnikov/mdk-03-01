## Запуск

```sh
cd src
dotnet build GroundStation/GroundStation.csproj
dotnet run --project GroundStation -- --init
dotnet run --project GroundStation
```

Нужен .NET 8 SDK. При инициализации задаются свои пароли `manager` и `operator`.
Хранилище создаётся в `src/data/station.json`; оператор закреплён за антенной 1.

## Новые команды

- `state` — смена состояния антенны с причиной (руководитель).
- `audit` — журнал с необязательными фильтрами по антенне, части причины и периоду UTC.
- `audit-migrate` — однократный перенос старой истории ТО; повторный запуск не создаёт дубликаты.

Период полуоткрытый: `[from, to)`. Время старых событий, если оно не было известно,
помечается как неизвестное. При фильтрации по времени такие записи исключаются.
